# Plan 2026-08-24 Météo V1

Tranche verticale complète : ingestion Open-Meteo → tables normalisées → règles
« bonne journée pour… » → bandeau + pastilles dans Aujourd'hui. Gouverné par
[[D-2026-08-24 Météo Open-Meteo]], [[D-2026-08-24 Tables Météo Normalisées]] et
[[D-2026-08-23 Pas De N8n Dans Le Cœur]].

## Étapes

### Domaine

- [x] `Domaine/Meteo/PrevisionHoraire.cs` et `PrevisionQuotidienne.cs` — modèle
      normalisé (heure/date, température, précip. mm + probabilité, vent + rafales,
      humidité, humidité du sol, couverture nuageuse, UV, lever/coucher côté
      quotidien). Aucune référence à la forme Open-Meteo.
- [x] `Domaine/Meteo/RegleJournee.cs` — abstraction : une règle reçoit les
      prévisions (horaires du jour + quotidiennes) et rend un `VerdictRegle`
      (`Bon` / `Passable` / `Defavorable` + raison française courte).
- [x] Règles v1 (seuils en constantes, ajustables par code) :
  - [x] `RegleTonte` — pas de pluie 12 h avant / 4 h après, prob. < 30 %,
        ≥ 10 °C, vent < 30 km/h ; l'humidité du sol module Bon → Passable.
  - [x] `RegleAeration` — fenêtres ouvertes : 18-26 °C, pas de pluie, vent < 25 km/h.
  - [x] `RegleJourneeDehors` — activités extérieures : heures de jour à 12-28 °C,
        prob. précip. < 30 %, vent < 30 km/h ; son inverse (pluie soutenue ou froid)
        rend « journée pour être en dedans » — un seul verdict dehors/dedans.
- [x] Tests unitaires des règles dans `server/HouseOs.Tests/Domaine/` (cas Bon,
      Passable, Défavorable, données manquantes).
